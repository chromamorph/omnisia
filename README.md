# OMNISIA and MaxTranPats (Version 20261001)

This repository contains the source code and executable JAR files for a Java system that implements a variety of algorithms and computational techniques for pattern matching, pattern discovery, data compression and analysis in multi-dimensional point sets. The functionality of the system is accessible through two programs, [OMNISIA](Points/src/com/chromamorph/points022/OMNISIA.java) and [MaxTranPats](MaxTranPatsJava/src/com/chromamorph/maxtranpatsjava/MaxTranPats.java). MaxTranPats can be used to process point sets with any number of dimensions, while OMNISIA is tailored to processing 2-dimensional pitch-time representations of music. The code is open-source, free software, released under the [GPL 3.0 licence](https://github.com/chromamorph/omnisia/tree/master?tab=GPL-3.0-1-ov-file#readme).
